Ce qu'une commande traverse avant de s'exécuter

Dans l'ordre réel du code de Hermes. Les deux premières barrières ne dépendent pas du modèle.

1

L'outil existe-t-il pour ce profil ?

Un jeu d'outils retiré (agent.disabled_toolsets) n'est même pas proposé au modèle.

Retiré : l'agent ne peut pas l'appeler.
↓
2

Plugin ou crochet pre_tool_call

Votre code examine chaque appel d'outil, avant son exécution.

Bloqué, la raison est renvoyée au modèle. S'il plante : bloqué aussi.
↓
3

Le socle absolu

Quelques commandes destructrices refusées dans tous les modes.

Toujours refusée, même en mode off.
↓
4

Votre liste de refus

approvals.deny : vos motifs interdits.

Refusée, même en mode off ou /yolo.
↓
5

Le mode d'approbation

smart (défaut), manual ou off, et les commandes déjà approuvées « toujours ».

Exécutée, refusée, ou la question vous est posée.
↓
✓

Exécution

Sur la machine, ou dans un conteneur si vous avez isolé le terminal.

La vie d'une tâche programmée

C'est la passerelle qui fait avancer l'horloge. Chaque passage repart d'une page blanche.

1 · Horloge

La passerelle vérifie

Les échéances sont contrôlées à intervalle régulier, tant que la passerelle tourne.

2 · Échéance

Session neuve

Aucun souvenir de vos conversations : la consigne doit tout contenir.

3 · Travail

L'agent exécute

Ou un script seul, sans modèle (--no-agent).

4 · Résultat

Livraison

La réponse finale part seule vers la destination choisie.

↓

--deliver telegram

Vers le canal d'accueil (/sethome), ou une conversation précise.

--deliver local

Dans ~/.hermes/cron/output/ sur la machine.

Réponse [SILENT]

Rien n'est envoyé, le résultat est archivé. Les échecs, eux, sont toujours livrés.

Brancher Telegram en six étapes

Trois se font dans Telegram, trois sur la machine où tourne Hermes.

ÉTAPE 1Telegram

Créer le bot

Écrire /newbot à @BotFather, choisir un nom terminé par bot.

ÉTAPE 2Telegram

Garder le jeton

BotFather donne un jeton secret. Qui l'a contrôle le bot.

ÉTAPE 3Telegram

Trouver son identifiant

Écrire à @userinfobot : il répond par un numéro.

ÉTAPE 4Machine

Brancher le bot

hermes gateway setup : jeton, puis identifiant autorisé.

ÉTAPE 5Machine

Essayer

hermes gateway run, écrire au bot, puis Ctrl+C.

ÉTAPE 6Machine

Laisser tourner

hermes gateway install puis hermes gateway start.
